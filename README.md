
# 🌱 Agro Forte - Futuro Sustentável

## Descrição

Projeto desenvolvido para demonstrar uma solução sustentável no agronegócio através de um bebedouro automático inteligente para animais.

## Objetivos

- Reduzir desperdício de água.
- Melhorar o bem-estar animal.
- Incentivar práticas sustentáveis.
- Aplicar tecnologia no meio rural.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Página responsiva.
- Apresentação do projeto.
- Simulação de economia de água.
- Interface moderna e interativa.
